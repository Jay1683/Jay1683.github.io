Bedrock Document Agents for Lending Operations

What we built

AWS Gen AI and Agentic AI  ·  Case 04

Multi Agent FinOps System on Bedrock

Limited visibility into AWS cost drivers, and FinOps processes run by hand, meant savings were being missed.

What we built
  • A supervisor led system of Bedrock agents covering cost analysis, cost optimisation, resource intelligence and data efficiency.
  • Lambda orchestration handling session management and tool execution across the agent set.
  • RAG over S3 and OpenSearch Serverless, drawing live data from RDS and external APIs.
  • Private API Gateway, WAF, Guardrails and cross region replication for security and resilience.
Outcomes
  • Real time cost visibility across the whole AWS estate.
  • Anomaly detection and spend forecasting in place of manual review.
  • Lower inference cost, through prompt caching and routing.

Bedrock · Lambda · OpenSearch Serverless · API Gateway · RDS · S3

AWS Data and Analytics  ·  Case 03

Resilient Loan Processing and Reporting Platform

Peak hour traffic and reporting ran against the same database, slowing loan processing, and business reports were still compiled by hand.

What we built
  • EC2 Auto Scaling behind an Application Load Balancer, spread across multiple Availability Zones.

  • WAF, KMS, CloudTrail and S3 cross region replication, the whole estate built as code with CloudFormation.
